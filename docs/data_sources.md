# Project Data Sources

## CMS Medicare DE-SynPUF

Primary synthetic healthcare claims source.

Planned datasets:

- Beneficiary Summary
- Inpatient Claims
- Outpatient Claims
- Carrier Claims
- Prescription Drug Events

Purpose:
Provide realistic Medicare beneficiary and claims structures without using real PHI.

Primary beneficiary linking key:

DESYNPUF_ID


## CMS Provider Data Catalog

Public CMS provider/reference data.

Purpose:

- Provider reference enrichment
- External healthcare data integration
- API ingestion demonstration


## Data Privacy

This portfolio project does not use real patient PHI.

Patient-level claims data comes from CMS synthetic public-use datasets.
Additional generated datasets, if required, will also be fully synthetic.
